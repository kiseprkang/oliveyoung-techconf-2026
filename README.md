# 올리브영 테크 컨퍼런스 참관기 (define:OMNI 2026)

사내 공유용 참관 리포트 정적 사이트입니다. 외부로 배포하지 마세요.

- `index.html`, `assets/` — 사이트 본문과 이미지·PDF
- `tools/build_assets.py` — 원본 사진에서 표시용 이미지·원본 다운로드 파일 생성 (원본 세션 폴더가 상위 폴더에 있어야 함)
- `tools/build_pdf.py` — 세션별 슬라이드형 PDF 생성 (`python tools/build_pdf.py`)
- 검색엔진 수집 차단: `robots.txt`, `<meta name="robots">`, `vercel.json`의 `X-Robots-Tag`
